# CRUI

Conquest Reborn UI addon suite, including the EllesmereUI-based modules and the NaowhUI companion.

Download the current stable package from [GitHub Releases](https://github.com/uncle-bone/CRUI/releases).

Extract the addon folders into `Interface/AddOns`. When upgrading from r22, remove the old `NaowhUI_EUI` folder; r23 uses `EllesmereUINaowhUI` and migrates its saved profile settings on load.
