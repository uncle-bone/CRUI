# CRUI — Conquest Reborn UI

> **[Download Here!](https://github.com/uncle-bone/CRUI/releases/latest/download/CRUI.zip)** · [Release notes](https://github.com/uncle-bone/CRUI/releases/tag/r23)
> **Current stable release: r23.**

A modular UI addon suite for Ascension: **Conquest of Azeroth / Conquest Reborn** (WoW 3.3.5a, Interface 30300), based on EllesmereUI and maintained by **Uncle Bone**.

CRUI brings configurable action bars, unit and raid frames, nameplates, class and power bars, cooldowns, bags, chat, minimap, DataBars, and quality-of-life features together in one addon suite. The NaowhUI companion adds its own settings section and curated UI options.

## Installation

1. Download the ZIP above.
2. Extract its addon folders into Conquest Reborn's `Interface/AddOns/` directory. Keep the folders side by side; do not nest them inside one another.
3. Enable EllesmereUI and the modules you want from the AddOns list.

When updating from r22, remove the old `NaowhUI_EUI` folder so only `EllesmereUINaowhUI` loads. Existing NaowhUI profile settings migrate on load. Keep your SavedVariables when updating.

## r23 notes

- Unit Frames' **Combo Points / Class Resource** display defaults to **None**; enable it in settings if desired.
- DataBars' **Bottom Info Bar** defaults to **Never**.
- The NaowhUI companion folder is now named `EllesmereUINaowhUI`.
- The r23 folder rename and settings migration still need in-game verification. The report that additional NaowhUI Top Bar options were not visible in r22 remains open.

CRUI is a community addon project and is not an official Ascension product.
