# CRUI r23 — Stable Release

- Renames the NaowhUI companion folder to `EllesmereUINaowhUI` and updates addon identity and media paths.
- Migrates its existing settings from the old EllesmereUI profile key.
- Carries forward r22 changes: NaowhUI companion settings pages and Top Bar controls, Unit Frames class resource display defaulting to None, and DataBars Bottom Info Bar defaulting to Never.
- Includes the NaowhUI companion license. ElvUI and WeakAuras payloads are excluded.

## Known verification status

The package is published to the stable release channel as requested. The r23 folder rename and settings migration have not been verified in-game. The tester previously reported that the additional NaowhUI Top Bar controls were not visible in r22; that report remains unresolved and should be checked after installation.
